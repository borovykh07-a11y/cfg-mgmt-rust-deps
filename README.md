# Инструмент визуализации графа зависимостей (Rust / Cargo)

## 1. Общее описание
CLI-инструмент на Python, который по имени пакета и URL репозитория Cargo строит транзитивный граф зависимостей. 
Инструмент поддерживает обход графа методом DFS (с рекурсией), корректно обрабатывает циклические зависимости, выводит порядок загрузки, строит ASCII-дерево, а также генерирует визуализацию графа на языке Mermaid с сохранением в PNG.

## 2. Описание всех функций и настроек
Все параметры задаются в INI-файле `config.ini`:
- `package_name` (str) - имя анализируемого пакета.
- `repo_url` (str) - URL репозитория или путь к тестовому файлу графа.
- `test_mode` (bool) - режим работы с тестовым репозиторием (true/false).
- `package_version` (str) - версия пакета (semver).
- `output_image` (str) - имя сгенерированного файла с изображением графа (PNG).
- `ascii_tree` (bool) - режим вывода зависимостей в формате ASCII-дерева.
- `max_depth` (int) - максимальная глубина анализа зависимостей.
