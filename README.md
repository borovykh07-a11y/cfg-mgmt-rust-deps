# Инструмент визуализации графа зависимостей (Rust / Cargo)

## 1. Общее описание
CLI-инструмент на Python, который по имени пакета и URL репозитория Cargo строит транзитивный граф зависимостей и визуализирует его.

## 2. Описание всех функций и настроек
Все параметры задаются в INI-файле `config.ini`:
- `package_name` (str) - имя анализируемого пакета
- `repo_url` (str) - URL репозитория или путь к тестовому файлу
- `test_mode` (bool) - true для тестового репозитория
- `package_version` (str) - версия пакета
- `output_image` (str) - имя PNG-файла
- `ascii_tree` (bool) - выводить ли ASCII-дерево
- `max_depth` (int) - максимальная глубина анализа
